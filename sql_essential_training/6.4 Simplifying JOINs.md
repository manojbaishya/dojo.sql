```sql
SELECT
 i.CustomerId AS [Customer Id],
 c.FirstName || ' ' || c.LastName AS [Customer Name],
 i.InvoiceId AS [Invoice Id],
 i.InvoiceDate AS [Purchase Date],
 i.Total AS Amount
FROM
 Invoice as i
INNER JOIN Customer as c ON
 i.CustomerId = c.CustomerId
ORDER BY
 c.CustomerId ASC,
 i.InvoiceDate ASC
LIMIT 100 OFFSET 0;
```

## How we have used JOIN Clauses

- Accessed fields in multiple tables
- Identified primary keys
- Identified similar foreign keys
- Used ON keyword to link the tables together
