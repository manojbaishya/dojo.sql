How is each city responding to global average sales?
- Global average sales amount
- Average sales per city


Procedure:
1. Query to display invoice data
2. Compare with aggregate function

```sql
SELECT 
    i.InvoiceDate AS [Invoice Date],
    i.BillingAddress AS [Billing Address],
    i.BillingCity AS [Billing City],
    i.Total AS [Billing Total]
FROM
    Invoice AS i 
WHERE
    i.total < 
        (
            SELECT AVG(Total)
            FROM Invoice
        )
ORDER BY
    i.Total DESC;
```
