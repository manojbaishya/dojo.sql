# Comments

1. Single line comments start with double dashes, example:
`-- This is a single line comment`
2. Block comments are enclosed as follows:
```sql
/*
This is a block comment.
*/
```

# Query Composition

1. Start with FROM master table
2. Do JOINS on other tables with join conditions
3. List all the data required as output in the SELECT clause with aggregation in addition.
4. Specify filters with WHERE clauses compounded by Booleans
5. Specify GROUP BY for the columns which are not aggregated. (Or we can use DISTINCT in SELECT output)
6. For filters on aggregate columns, use HAVING clause
7. Specify sorting of results using ORDER BY clause with one or multiple columns by ASC or DESC
8. Specify the pagination of results using `OFFSET <X> ROWS FETCH NEXT <Y> ROWS ONLY` (or the equivalent syntax for database in use)

# Aliases

1. Using aliases on columns with `SELECT tbl.colname AS business_friendly_name`
2. Using aliases on tables with `FROM table1 AS t1 INNER JOIN table2 AS t2 ON t2.fkey = t1.pkey`
3. Aliases can be surrounded with brackets, quotes (single / double) or nothing in case of single words.

# Sorting

Use ORDER BY clause to sort a column by name or alias

`ORDER BY tbl.colname ASC`

`ORDER BY tbl.colname DESC`

`ORDER BY col_alias ASC`

`ORDER BY col_alias DESC`

Specify multiple columns for compound sorting

```sql
ORDER BY
	tbl.col1 ASC, -- Primary sorting field
	tbl.col2 DESC, -- If multiple values of tbl.col1 field are equal, use tbl.col2 to sort amongst them
	tbl.col3 ASC -- Ditto for tbl.col2
```

# Pagination

Use `OFFSET <X> ROWS FETCH NEXT <Y> ROWS ONLY` for limiting search results
