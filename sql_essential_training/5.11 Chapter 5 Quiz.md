In the Execute SQL tab of DB Browser for SQLite, how many invoices were billed to the city of Brussels?

```sql
SELECT 
	COUNT(InvoiceId)
FROM Invoice AS i
WHERE
	BillingCity = 'Brussels';
```

What is the correct syntax for the CASE statement?

```sql
SELECT
        FirstName,
        LastName,
        Company,
        Country,
        CASE        
                WHEN Country = 'USA' THEN 'Local' 
                ELSE 'Global' 
        END AS Region
FROM        
        Customer
ORDER BY
        Region

```
